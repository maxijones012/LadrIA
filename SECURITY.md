# Seguridad y privacidad

Este proyecto está en etapa experimental. No incorporen claves de firma, tokens de cuenta, secretos de AdMob, secretos de Supabase ni materiales privados de usuarios en GitHub.

**Medios:** los sonidos y videos se analizan localmente en la base MVP. Integraciones futuras de red serán optativas/visibles y limitadas a anuncios, saldo de créditos, consentimiento y releases. Los reportes no diagnostican conducta animal.

**Créditos:** nunca confiar en saldo, pantalla de recompensa o callback local como fuente de verdad. Si se activa monetización, el servidor debe validar firmas AdMob SSV y llevar un ledger transaccional.

**Reportar incidentes:** preferir un canal privado al responsable del repositorio; no crear issues públicos con secretos o datos sensibles. Si se filtra una clave, revocarla y rotarla.

**Instaladores:** solo descargar releases oficiales HTTPS y verificar la firma del APK, no instalar ejecutables de terceros que usen el nombre LadrIA.
